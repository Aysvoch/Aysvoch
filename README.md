## Что делаю

- **Discovery** - ищу проблему до того, как выбирать решение.
- **Аналитика** - превращаю сырые данные в продуктовые метрики.
- **MVP** - довожу идею до работающего продукта, а не до презентации.
- **Дисциплина вывода** - развожу факт, наблюдение, гипотезу и причину.
